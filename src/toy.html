Toy validation of the phonon upfolding

A two-dimensional lattice small enough to compare every number with an exact calculation. Updated 2026-10-01.

All checks pass. The toy validates the phonon upfolding only; it contains no electrons, vertices or rates.

Model

Square lattice of \(121\times121\) sites with open boundaries, one scalar displacement per site, nearest-neighbour springs \(K=1\) and masses \(M=1\). The defect sits at the centre: mass \(M'\) and spring \(K'\) on its four bonds. The on-site terms are built from the springs, so the acoustic sum rule holds, and the matrix is weighted by the defect masses, so it is static and Hermitian:

\[\mathcal D_{ij}=\frac{\Phi_{ij}}{\sqrt{M_iM_j}},\qquad \Phi_{ii}=\sum_{j\ne i}K_{ij},\qquad \Phi_{ij}=-K_{ij}\quad(i\ne j) .\]

The host band is \(0\le\omega\le2\sqrt2\approx2.828427\). Two defects are tested: a light defect \(M'=0.3,\ K'=1.3\), which pushes a local mode above the band, and a heavy defect \(M'=8,\ K'=0.6\), which produces a low-frequency resonance inside the band.

Cluster and chain

The cluster is the Manhattan ball of radius 2 around the defect (13 sites); it contains every mass and spring change. The bath is the remaining 14 628 sites. The coupling \(\mathcal D_{bc}\) has rank 8, the number of cluster sites on the cluster boundary, which sets the block width of the chain.

The chain is built once, 160 blocks with full reorthogonalization in 15.5 s, and is used unchanged for both defects and for the pristine reference. The code asserts that \(\mathcal D_{bc}\) of each defective lattice equals the host coupling.

Unit tests

python -m pytest tests runs eight tests on a \(41\times41\) lattice in about 8 s:

  • the Lanczos blocks are orthonormal;
  • the coupling block is the same for the host and for both defects;
  • with 12 chain blocks the local mode equals the largest eigenvalue of the full lattice to \(10^{-9}\);
  • continued fraction and mode sum agree to \(10^{-10}\) relative;
  • for the pristine lattice (null test), the light defect and the heavy defect, the continued fraction reproduces the exact cluster Green function at \(\eta=0.3\) to \(10^{-6}\) relative;
  • the damped companion matrix (Eq. 9 of Lihm and Park) reproduces \(\big[(\omega+i\Gamma)^2-\tilde C\big]^{-1}\) to \(10^{-10}\), and its eigenvalues lie in the lower half plane.

What this does not validate

  • Scalar displacements: no tensor force constants, no rotational sum rules, no flexural ZA branch.
  • A finite lattice with open boundaries. The exact reference uses the same lattice, so the comparison is like for like, but it is not the infinite-crystal limit.
  • No electrons: the static vertices, the scattering states and the distorted-wave rates are untested.
  • Full reorthogonalization: affordable here, but a first-principles bath with \(10^5\)–\(10^6\) coordinates needs partial reorthogonalization or the Stieltjes route from a cached spectral density.

Reproduce

python examples/square_lattice_toy.py prints the tables above (about one minute, mostly building the chain). Environment for the numbers on this page: Python 3 with NumPy 2.4.0 and SciPy 1.16.3.
